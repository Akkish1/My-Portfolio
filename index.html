Featured build · Claude Code

An executive risk and compliance dashboard, built by me with Claude Code

More than 120 risks, remediation items, production bugs and security vulnerabilities were open at once, and leadership couldn't see what needed attention between reviews. So I built the view they needed.

The problem

With 120+ items open at once, there was no single view of what was on track, what was slipping and what needed leadership's help.

What I built

An executive risk and compliance dashboard that pulls the data together, so every item shows its owner, remediation plan and escalation path. I built it myself with Claude Code.

How it was used

It backed the governance reviews: owners were accountable for dates, and leadership could see what needed escalation between reviews.
